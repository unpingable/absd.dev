UPTIME(1)                   General Commands Manual                  UPTIME(1)

NAME
       uptime -- how long this boot has run, and which boot it is

SYNOPSIS
       uptime

DESCRIPTION
       uptime prints one line:

             up 0 days 00:12:34, 754434 ticks since boot, boot 3f2a...

       The time is counted by the kernel's boot tick counter: timer interrupts
       since the kernel started, about 1000.15 a second (PIT channel 0).  It
       restarts at zero every boot and never goes back within one.  It counts
       interrupts delivered, so under emulation it can run slower than real
       time; it is not the real-time clock (date(1)).

       The boot is the kernel's boot identity: 16 bytes, shown in hexadecimal,
       drawn once when the kernel starts and never the same for two boots.
       The file server writes it into /var/log/fsd when it starts, so a log
       line can be matched to its boot.

       There is no load average and no count of users or sessions; see ps(1)
       for this session's processes.

EXIT STATUS
       0, or 2 when given any argument.

SEE ALSO
       date(1), ps(1), afterboot(8)
