MAN(1)                      General Commands Manual                     MAN(1)

NAME
       man -- print manual pages

SYNOPSIS
       man [section] name
       man -k word

DESCRIPTION
       man prints the manual page name to standard output.  With section (a
       digit, 1 to 9) it looks only in that section; otherwise it searches the
       sections in the order 1, 8, 6, 2, 3, 5, 7, 4, 9 and prints the first
       page it finds.

       With -k it prints the index line of every page whose name or one-line
       description contains word, ignoring ASCII case.

       The pages are plain text.  They are written in mdoc, the BSD manual
       page macro language, and rendered on the build host, with a pinned GNU
       groff, when the system image is built; ABSD itself has no roff
       formatter and no pager.  The page is copied to standard output
       unchanged; to read part of a long page, pipe it through head or tail,
       for example `man afterboot | head -n 40'.

       A page name contains only letters, digits, `.', `_', and `-', and does
       not start with `.'; anything else, such as a path, is refused.  There
       are no other options and no MANPATH.

FILES
       /share/man/catS/name.0  the rendered page name of section S

       /share/man/whatis       the index -k searches: one line per page,
                               `name(S) - description'

       /share is mounted read-only in every SSH session.

EXIT STATUS
       0 when a page, or at least one index line, was printed; 1 when there is
       no such page, nothing matched, or a file could not be read; 2 for a
       usage error or an invalid page name.  When the reader of its output
       goes away (`man intro | head -n 5') man stops at once, silently, with
       status 1; there is no signal to stop it.

EXAMPLES
             absd$ man 7 handles
             absd$ man -k file
             filesystem(7) - the ABSD filesystem and its file server
             absd$ man nosuchpage
             man: no entry for nosuchpage in the manual
             absd-sh: man: exit status 1

DIAGNOSTICS
       man: no entry for NAME in the manual
               No section has a page of that name; with a section given, "in
               section S of the manual".

       man: /share/man: ...: no manual is visible to this process
               The process has no view of /share, for example under `nofs man
               intro'.
