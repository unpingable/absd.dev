REBOOT(8)                   System Manager's Manual                  REBOOT(8)

NAME
       reboot -- restart a served ABSD machine

SYNOPSIS
       reboot

DESCRIPTION
       reboot is `shutdown -r now': the SSH server ends every session in
       order, the file server commits and stops, and init restarts the
       machine, which boots the same image again.  It takes no arguments.  Ask
       with `ssh host reboot' or type it to an interactive absd-sh(1); see
       shutdown(8) for what happens, who may ask, and the exit status.

DIAGNOSTICS
       On the serial console the sequence of shutdown(8) with
       `action=restart', then `MACHINE RESTART ARMED pid=1' and `MACHINE
       RESTART'.

SEE ALSO
       absd-sh(1), shutdown(8)

QUALIFICATION
       Qualified under QEMU's i440fx machine, which resets on the first of the
       three methods the kernel tries (the 0xcf9 reset register, the keyboard
       controller, a triple fault).  QEMU must be allowed to reboot: under
       -no-reboot without -no-shutdown it exits with status 0 instead, and
       with both it pauses.  None of the three methods is tested on a physical
       machine.
